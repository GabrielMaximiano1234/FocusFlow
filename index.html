Dúvidas Frequentes

Esclareça suas dúvidas sobre o FocusFlow e o funcionamento das assinaturas.

Como funciona a simulação de planos no app?
Você pode alterar seu plano a qualquer momento dentro da Área do Cliente (app.html). Ao fazer o upgrade, o sistema emite um novo Token de segurança JWT criptografado em tempo real e libera os recursos correspondentes instantaneamente.
O que acontece se eu acessar a área logada sem estar autenticado?
A Área do Cliente está blindada por um Route Guard. Caso você tente acessar diretamente a página app.html sem um JSON Web Token (JWT) válido no storage do navegador, você será imediatamente barrado e direcionado para a tela de login.
O Stripe é integrado de verdade?
Os links de pagamento nesta Landing Page comercial estão preparados para receber as sessões de checkout do Stripe Live/Test. No momento, eles apontam para as URLs oficiais de simulação de pagamento do Stripe Checkout.
